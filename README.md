# BotVerse Dashboard

لوحة تحكم عربية للبوت مع رابط مباشر إلى Discord OAuth، قائمة السيرفرات، وإعدادات أساسية.

## التشغيل

1. انسخ ملف `.env.example` إلى `.env.local`
2. ضع بيانات Discord الخاصة بك
3. شغّل المشروع:

```bash
npm install
npm run dev
```

4. شغّل البوت:

```bash
npm run bot
```

## ملاحظات
- لا تضع التوكن داخل GitHub
- التوكن يُستخدم فقط من الخادم
- أضف Discord OAuth في Developer Portal
